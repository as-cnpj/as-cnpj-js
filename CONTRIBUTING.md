# Contribuindo

Idiomas: **Português (Brasil)** | [English](CONTRIBUTING.en.md) | [Español](CONTRIBUTING.es.md) | [Français](CONTRIBUTING.fr.md)

## Modelo de manutencao

O `as-cnpj-js` aceita contribuicoes, mas opera com curadoria central do maintainer.

- PRs externos sao bem-vindos;
- a decisao final de merge fica com os maintainers;
- uma proposta pode ser rejeitada se divergir do contrato da biblioteca ou da estrategia do ecossistema.

## Tipos de contribuicao aceitos

- correcao de bug;
- melhoria de documentacao;
- novos vetores de teste;
- hardening de testes;
- hardening de seguranca;
- melhorias de build, CI e release;
- melhorias de ergonomia sem quebrar o contrato publico.

## Mudancas que exigem alinhamento previo

Abra issue ou discussion antes de enviar PR para:

- mudanca de API publica;
- mudanca do algoritmo;
- mudanca de naming;
- mudanca de licenca;
- mudanca estrutural do repositorio.

## Review

Todo PR precisa de review de pelo menos um maintainer listado em `CODEOWNERS`.

## Seguranca

Nao use issue publica para vulnerabilidades. Consulte [SECURITY.md](SECURITY.md).
